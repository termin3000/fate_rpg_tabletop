================================================================
  FATE RPG VTT  -  Виртуальный стол для настольных ролевых игр
================================================================

ЧТО ЭТО
----------
Это программа для игры в Fate Core/Accelerated через интернет.
Ведущий (GM) создаёт комнату, игроки подключаются по коду —
и все видят одну и ту же карту, кубики, листы персонажей.


ЧТО НУЖНО ДЛЯ ЗАПУСКА
----------------------
Только Windows 10 или 11 (64-бит) и интернет.
Ничего отдельно скачивать или настраивать НЕ надо —
всё сделает файл start.bat


КАК ЗАПУСТИТЬ (3 ШАГА)
----------------------
1. Распакуйте эту папку в любое место
   (например, в Документы или на Рабочий стол).
   ВАЖНО: не запускайте из архива — сначала распакуйте!

2. Дважды кликните на файл  start.bat

3. Подождите 2-5 минут при первом запуске
   (скачиваются нужные программы — это один раз).
   При следующем запуске будет за 10-15 секунд.

   Во время установки Windows может спросить разрешение —
   нажмите "Да" или "Разрешить".

Когда всё готово — сам откроется браузер с приложением.


ЕСЛИ start.bat НЕ ЗАПУСКАЕТСЯ
-----------------------------
Если двойной клик по start.bat ничего не делает или окно
сразу закрывается:

1. СНИМИТЕ БЛОКИРОВКУ WINDOWS:
   - Правый клик на start.bat → Свойства
   - Внизу вкладки "Общие" если есть кнопка "Разблокировать" —
     нажмите её и нажмите OK
   (Windows помечает файлы из интернета как небезопасные)

2. ЗАПУСТИТЕ ОТ ИМЕНИ АДМИНИСТРАТОРА:
   - Правый клик на start.bat → Запуск от имени администратора

3. ЗАПУСТИТЕ ЧЕРЕЗ КОМАНДНУЮ СТРОКУ:
   - Откройте cmd (Пуск → введите cmd)
   - Перетащите start.bat в окно cmd и нажмите Enter
   - Так вы увидите ошибку если что-то не так

4. ОТКЛЮЧИТЕ АНТИВИРУС ВРЕМЕННО:
   - Касперский, ESET, Dr.Web могут блокировать .bat файлы
   - Добавьте папку fate-rpg-portable в исключения

5. ЕСЛИ BUN НЕ УСТАНАВЛИВАЕТСЯ:
   - Откройте https://bun.sh в браузере
   - Скачайте установщик для Windows
   - Запустите его
   - Перезагрузите компьютер
   - Запустите start.bat снова


КАК ИГРАТЬ
----------
• ВЕДУЩИЙ (GM):
  - Нажмите иконку "Сеть" в шапке (знак Wi-Fi / глобус)
  - Введите своё имя
  - Нажмите "Создать комнату"
  - Появится 6-буквенный код (например K7P9MQ)
  - Передайте этот код игрокам (можно показать QR-код)

• ИГРОКИ:
  - Откройте приложение (другой браузер / другой компьютер /
    телефон — см. ниже "Как играть с других устройств")
  - Нажмите иконку "Сеть"
  - Введите имя и код от ведущего
  - Нажмите "Подключиться"

Ведущий может назначить каждому игроку персонажа.
Игроки бросают кубики — все видят результат.


ССЫЛКА ДЛЯ ПОДКЛЮЧЕНИЯ (УДОБНЕЕ, ЧЕМ КОД)
------------------------------------------
Когда вы создали комнату, в окне "Сетевая игра" есть поле
"Ссылка для подключения". Игрок может просто открыть её в браузере —
и код комнаты подставится автоматически.

СПРАВА от поля ссылки есть кнопка со стрелкой вниз (v) —
она открывает выбор адреса. Доступны варианты:

  • "Этот компьютер"      — http://localhost:3000/...
    (только если игрок на этом же компьютере)

  • "Локальная сеть — IP" — http://192.168.x.x:3000/...
    (для телефонов и ноутбуков в той же Wi-Fi сети)
    ВАЖНО: при первом запуске Windows спросит "Разрешить доступ
    приложению Node.js в частных сетях?" — нажмите "Разрешить".

  • "Интернет-туннель (Cloudflare)" — HTTPS-ссылка вида
    https://random-words-123.trycloudflare.com
    (для игроков из ЛЮБОЙ сети — интернет-игра без настройки роутера!)
    Нажмите кнопку "Создать ссылку для интернета" — программа сама
    скачает cloudflared (один раз, ~15 МБ) и создаст публичную ссылку.
    Бесплатно, без регистрации. Отправьте ссылку друзьям — они
    откроют её в браузере и подключатся к вашей комнате.
    Чтобы остановить туннель — нажмите "Остановить туннель".

  • "Публичный IP"        — http://внешний-IP:3000/...
    (для игроков из другой сети — нужен порт-форвардинг на роутере)
    Сложнее, чем туннель. Используйте только если туннель не работает.

  • "Свой адрес"          — введите адрес своего туннеля (например
    my-tunnel.ngrok-free.app) и нажмите "ОК"

По умолчанию выбирается адрес локальной сети — это самый частый
случай (игра дома с друзьями через общий Wi-Fi).

Для игры через интернет САМЫЙ ПРОСТОЙ СПОСОБ — кнопка
"Создать ссылку для интернета" (Cloudflare Tunnel).
Не требует настройки роутера, регистрации, или установки
отдельных программ. Одна кнопка → публичная ссылка.


КАК ИГРАТЬ С ДРУГИХ УСТРОЙСТВ (телефон, второй ноут)
----------------------------------------------------
По умолчанию приложение работает только на этом компьютере.
Чтобы зайти с телефона или другого ПК в той же Wi-Fi сети:

ПРОСТОЙ СПОСОБ (рекомендуется):
1. Запустите start.bat на этом компьютере
2. Создайте комнату (см. выше "Как играть")
3. В окне "Сетевая игра" нажмите кнопку со стрелкой вниз (v)
   рядом с полем "Ссылка для подключения"
4. Выберите "Локальная сеть — ваш_IP"
5. Скопируйте ссылку (иконка цепочки) и отправьте игрокам
   (например, в Telegram / WhatsApp / на почту)
6. Игроки открывают ссылку на телефоне — комната подставится сама

При первом запуске Windows спросит, разрешить ли доступ к Node.js
в частных сетях — нажмите "Разрешить". Иначе телефон не подключится.


КАК ИГРАТЬ ЧЕРЕЗ ИНТЕРНЕТ (из другой сети)
------------------------------------------
Если друзья не в той же Wi-Fi сети (например, в другом городе):

САМЫЙ ПРОСТОЙ СПОСОБ — Cloudflare Tunnel (встроено в программу):
1. Запустите start.bat, создайте комнату
2. В окне "Сетевая игра" нажмите кнопку со стрелкой вниз (v)
   рядом с полем "Ссылка для подключения"
3. Нажмите кнопку "Создать ссылку для интернета"
4. Подождите 10-20 секунд (при первом запуске скачается cloudflared,
   ~15 МБ — это один раз)
5. Появится ссылка вида https://random-words-123.trycloudflare.com
6. Скопируйте её и отправьте друзьям (в Telegram, WhatsApp, и т.п.)
7. Друзья открывают ссылку в браузере — комната подставится сама

Преимущества:
  • Без настройки роутера (не нужен порт-форвардинг)
  • Без регистрации (не нужен аккаунт Cloudflare)
  • Бесплатно (trycloudflare — бесплатный сервис)
  • HTTPS (защищённое соединение)
  • Работает через любые NAT / файрволы

Чтобы остановить туннель — нажмите "Остановить туннель".
Туннель живёт пока работает программа. Если закрыть start.bat —
туннель тоже закроется.

ЧЕРЕЗ ШЛЮЗ (для корпоративных сетей с блокировкой портов):
1. Узнайте IP-адрес этого компьютера:
   - Откройте Командную строку (cmd)
   - Введите:  ipconfig
   - Найдите строку "IPv4-адрес" — например 192.168.1.50
2. Запустите  start-gateway.bat  (он сам скачает шлюз Caddy)
3. На телефоне / втором компьютере откройте в браузере:
   http://ВАШ_IP:81
   (например: http://192.168.1.50:81)


КАК ОСТАНОВИТЬ
--------------
Просто закройте чёрное окно, где запущен start.bat
Серверная часть (signaling) закроется автоматически.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• "Bun не установлен" — откройте https://bun.sh ,
  скачайте установщик для Windows, запустите, потом снова start.bat

• Не открывается браузер — откройте вручную: http://localhost:3000

• "physics-service connection timeout" или не работает физика кубиков:
  - Физика кубиков работает через отдельный сервер (порт 3006)
  - При первом запуске он может не успеть установиться
  - ПЕРЕЗАПУСТИТЕ start.bat — при втором запуске всё должно заработать
  - Если не помогает: в приложении откройте Настройки (иконка шестерёнки)
    и переключите "Режим кубиков" с 3D на 2D — 2D-режим работает без сервера

• Броски кубиков не доходят до игроков —
  проверьте, что оба в одной сети и порт 81 открыт в брандмауэре

• Ошибка "Cannot find module @prisma/client..." —
  удалите папку node_modules и запустите start.bat заново

• Совсем ничего не помогает — удалите папку node_modules,
  удалите папку .next (если есть), запустите start.bat заново


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Все ваши приключения, персонажи и заметки — в файле:
   db\custom.db
Это SQLite-база. Для резервной копии просто скопируйте этот файл.
